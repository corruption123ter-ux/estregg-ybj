  [ CONTROLS ]
  ----------------------------------------------
  Arrow Keys   : Manual Flight & Navigation
  A            : Autopilot Toggle / Jump Galaxy
  B            : Nudge Right (Precision Thrust)
  X            : Nudge Left (Precision Thrust)
  Y            : Nudge Up (Precision Thrust)

  [ SYSTEM SET ]
  ----------------------------------------------
  I            : Flagged Planets & System Progress
  R            : Inspect Nearest Star Class (R3)
  3            : Open Game Settings Menu

  [ TERMINAL & SYSTEM EXIT ]
  ----------------------------------------------
  Ctrl + E     : Open Secret In-Game Command Prompt
  Ctrl + S     : Quick-Save Game Progress
  Ctrl + B / Q : Exit Game Immediately
  0 / Esc / Q  : Close Current Overlay Menu
