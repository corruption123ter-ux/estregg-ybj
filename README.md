# estregg-ybj

A terminal-based Python game built by Yb_Jeorgie that was built with tool `curses`. Run it directly inside your Linux environment!

---

## 🛠️ Requirements & Installation

To run `estregg-ybj`, you need **Python 3** and **pipx** installed on your system.

### Step 1: Install System Dependencies
Run the following command to update your packages and install Python along with `pipx`:

bash:

sudo apt update && sudo apt install -y python3 python3-pip pipx
pipx ensurepath

> Note: If this is your first time installing pipx, close and reopen your terminal after running pipx ensurepath so your environment updates properly. 

# Step 2: Install estregg-ybj
Install the package globally in an isolated environment using pipx:

pipx install estregg-ybj

> Note: If you already have estregg-ybj installed and want to update to the latest version, run:

pipx upgrade estregg-ybj

# 🚀 Launching the Game
Once installed, start the game anytime by executing:

estregg

### macOS Installation

Open your terminal and use **Homebrew** to install pipx:

```bash
brew install pipx && pipx ensurepath
```

*(Note: If this is your first time installing pipx, close and reopen your terminal window after running the command so your system paths update properly).*

### Android (Termux) Installation

1. Open Termux and update your packages:
   ```bash
   pkg update && pkg upgrade -y
   ```
2. Install Python and pipx prerequisites:
   ```bash
   pkg install python pip -y
   pip install pipx
   pipx ensurepath
   ```
   *(Note: Close and reopen Termux after running this so your terminal path updates).*

3. Install and launch the game:
   ```bash
   pipx install estregg-ybj
   estregg
   ```

*Tip: Because mobile screens lack arrow keys, it is highly recommended to use a physical keyboard or an app like **Hacker's Keyboard** to play.*
